# Repository instructions

## Language

- Write all documents, issues, commit messages, pull request titles, descriptions, and comments in English.
- Other languages are allowed only in explicitly localized files or paths, such as `README-ko.md` and `runtime-ko.md`.
- Keep the primary documentation in English. Put translations in separate locale files instead of mixing languages in one document.
- These rules apply to future work and to documents updated during the current task.

## Style

- Never use em dashes. Use hyphens or colons instead.
